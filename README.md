# ASHSPORE
Phone-first 2.5D platformer. Walk the hold. Tend the bloom. Run the wilds.

Open `index.html` on your phone. Add to Home Screen for fullscreen.

## Loop
- Walk and jump through the cut-stone hold.
- Stand on a room and tap ACT to post tribe, take stores, or raise a hollow.
- Climb the shaft (jump while touching the ladder).
- Gate: wear a body and run a land until you claim its shrine.
- Altar: spend DNA, grow veins between blooming lands, outrun the rival rite.
